# Finance Dashboard Demo

A React + TypeScript financial dashboard built with Vite, with interactive charts, filterable tables, and KPI calculations.

**This public repository serves synthetic demonstration data only.** Dates, amounts, merchants, and account labels in the fixture are invented. The fixture is generated independently of any financial export. Never commit personal or client financial records, statements, screenshots, or exports.

## Features

- Income, expense, net position, and savings rate cards
- Monthly, category, bank, merchant, and spending group charts
- Sortable and paginated transactions
- Date, amount, and category filters
- Browser-local demo transaction edits

## Quick Start

```bash
npm ci
npm run data:generate
npm run check:data
npm run dev
npm run build
npm run preview
```

The development, build, and preview commands run the data-safety guard first.

Enable the staged-file pre-commit guard in each clone:

```bash
npm run hooks:install
```

Run the guard regression tests with `npm run test:data`.

## Public Data Policy

`public/data/transactions.json` is a deterministic synthetic fixture generated by the script in `scripts/`. Its metadata explicitly identifies it as synthetic, and the dashboard displays a demonstration-data notice.

The guard checks the fixture against the generator's exact output. Adding a `synthetic` label to a real export does not pass the check. It also rejects export files and structured transaction datasets outside the approved fixture.

Everything in `public/` is directly downloadable and copied into the production build. Authentication on a dashboard page cannot protect an asset in this directory. Private data requires a separate authenticated service with server-side access controls; this repository does not provide one.

Raw exports belong outside the repository and outside `public/`. The ignored `private-data/` and `exports/` directories are precautionary exclusions, not permission to publish their contents. Do not force-add ignored files.

## Updating Demo Data

1. Change only invented fixture inputs in the generator.
2. Run `npm run data:generate`.
3. Run `npm run check:data` and `npm run build`.
4. Review and commit the safe generated fixture together with its generator.

Do not replace the fixture with a bank, accounting, spreadsheet, or client export. Do not paste financial records into documentation or test cases.

```text
.github/workflows/      Automated data-safety checks
```

## Data Contract

The fixture includes `transactions`, `metadata`, and `filterOptions` as defined in `src/types/index.ts`. Each record has an invented demo ID, date, merchant, description, account label, category, spending group, type, and amount. Metadata includes `synthetic: true`, a fixture version, and computed ranges. Bank names are generic institution labels used by the existing application schema and do not identify anyone's account.

## Browser Storage

Demo edits use separate browser-storage keys from earlier personal-data versions. Existing browser-local records are not read by this demo and are not erased by this change. If you used an earlier version, review and clear that site's old storage yourself after privately preserving anything you need. Do not enter genuine financial records into the public demo.

## Customisation

- Chart colours and currency: `src/lib/constants.ts`
- Data types: `src/types/index.ts`
- Aggregations: `src/lib/dataTransform.ts`
- New charts: `src/components/charts/`

Currency is configured for South African rand (ZAR).

## Guard Limitations

Git ignores and local hooks can be bypassed, and CI runs after a push. The guard catches the approved fixture being replaced and common export forms; it is not a general personal-data detector. Keep the guard enabled, review changes, and never upload private data. History and already-published copies require separate cleanup.
